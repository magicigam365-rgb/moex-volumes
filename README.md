# MOEX Volumes

Программа автоматически настраивает стаканы в FSR Launcher и EasyScalp — загружает объёмы с биржи и записывает их за вас.

Работает на Windows.

---

## Что делает

- Считывает обороты с MOEX за последние дни
- Рассчитывает крупный лот и пороги для стаканов
- Записывает всё в FSR и EasyScalp одной кнопкой
- Встроенная справка — нажмите «Справка» в программе
- Автообновление — при запуске проверяет, есть ли новая версия

## Как пользоваться

1. Запустите `MOEX_Volumes.exe`
2. Выберите счёт из списка — программа сама найдёт подключённые пропы
3. Нажмите «Загрузить»
4. Готово

**Важно:** перед загрузкой закройте EasyScalp. FSR можно не закрывать.

## Настройки

Все настройки уже предустановлены. При необходимости можно изменить:

- **Торговых дней** — сколько дней учитывать для расчёта (по умолчанию 5)
- **Заполнение** — порог заполнения стакана (по умолчанию 0.5)
- **Объём 1** — порог крупного объёма (по умолчанию 1.0)
- **Объём 2** — порог очень крупного объёма (по умолчанию 2.0)
- **Цена пункта** — стоимость одного пункта в рублях или в процентах от контракта
- **Рабочие объёмы** — множители для рабочих объёмов (по умолчанию 1, 2, 3, 0.5)

Настройки сохраняются автоматически.

## Какие счёта поддерживаются

Программа сама находит все подключённые пропы:

- **FSR Launcher** — все пропы, которые есть в папке MVS
- **EasyScalp** — все пропы, у которых есть Trade-файлы
- **Крипто** — BINAD, BYBITD

## Обновление

При запуске программа проверяет, вышла ли новая версия. Если да — предложит скачать с прогресс-баром.

## Проблемы и решения

| Проблема | Решение |
|----------|---------|
| Рабочие объёмы равны нулю | Проверьте цену пункта. Для крипты попробуйте режим «%» |
| Стаканы не обновились | Закройте EasyScalp и попробуйте снова |
| Программа не запускается | Положите рядом с exe файл `config.json` |
