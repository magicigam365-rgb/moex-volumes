# MOEX Volumes

Программа автоматически настраивает стаканы в FSR Launcher и EasyScalp — загружает объёмы с биржи и записывает их за вас.

Работает на Windows.

---

## Как пользоваться

**Перед загрузкой:**
1. Сохраните резервную копию config.json (ваши настройки)
2. Закройте FSR и EasyScalp

**Запуск:**
1. Запустите `MOEX_Volumes.exe`
2. Выберите счёт — программа сама найдёт подключённые пропы
3. Нажмите «Загрузить»
4. Готово

## Настройки

Все настройки уже предустановлены. Менять не нужно, если только:

- **Торговых дней** — сколько дней учитывать (по умолчанию 5)
- **Заполнение** — порог заполнения стакана (по умолчанию 0.5)
- **Объём 1** — порог крупного объёма (по умолчанию 1.0)
- **Объём 2** — порог очень крупного объёма (по умолчанию 2.0)
- **Цена пункта** — рубли или процент от контракта (для крипты)
- **Рабочие объёмы** — множители (по умолчанию 1, 2, 3, 0.5)

Настройки сохраняются автоматически.

## Какие счёта поддерживаются

Программа сама находит все подключённые пропы:

- **FSR Launcher** — все пропы из папки MVS
- **EasyScalp** — все пропы с Trade-файлами
- **Крипто** — BINAD, BYBITD

## Автообновление

При запуске программа проверяет, вышла ли новая версия. Если да — предложит скачать.

## Проблемы

| Проблема | Решение |
|----------|---------|
| Объёмы равны нулю | Проверьте цену пункта. Для крипты попробуйте «%» |
| Стаканы не обновились | Закройте привод и попробуйте снова |
